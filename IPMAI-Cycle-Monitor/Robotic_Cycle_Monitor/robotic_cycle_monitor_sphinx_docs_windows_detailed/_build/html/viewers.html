Raw CSV Viewer¶

run_1_robotic_raw_csv_viewer.py

Features:

  • synchronized x-axis,

  • rectangle zoom,

  • blue signal traces,

Results Viewer¶

run_4_robotic_results_viewer.py

Features:

  • PCA 2-D weight map,

  • weight heatmap,

  • saliency heatmap,

  • MLP diagnostics,

  • file index mapping,

  • continual monitoring diagnostics.

PCA visualization¶

  • blue circles: runs,

  • red square: reference run.

Heatmaps¶

Heatmaps use:

  • x-axis: file/run index,

  • y-axis: weight or embedding index.
