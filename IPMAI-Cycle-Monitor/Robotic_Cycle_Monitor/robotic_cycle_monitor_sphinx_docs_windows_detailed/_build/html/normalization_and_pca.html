Normalization, PCA, and Weight-Space Interpretation¶

Normalization¶

Signals are normalized using the statistics defined by the corresponding reference data or reference run. In the notation of this documentation, a normalized scalar signal is written as

\[z(k)=\frac{x(k)-\mu_x}{\sigma_x+\varepsilon}.\]

When multiple variables are processed jointly, the normalized feature vector is denoted by \(\mathbf{x}(k)\).

PCA embedding¶

PCA may be used to suppress collinearity and to obtain a compact embedding for LNU learning. Let \(\mathbf{X}\) denote the data matrix whose rows are samples and whose columns are variables or delayed features. PCA gives a loading matrix \(\mathbf{V}\). The embedded data are

\[\mathbf{Z}=\mathbf{X}\mathbf{V}.\]

If only the first \(m\) components are retained, then

\[\mathbf{Z}_m=\mathbf{X}\mathbf{V}_m.\]

Weight-space PCA¶

For visualization of learned run states, the final LNU weight vectors may be stacked into a matrix

\[\begin{split}\mathbf{W}=\begin{bmatrix} (\mathbf{w}^{(1)})^T\\ (\mathbf{w}^{(2)})^T\\ \vdots \end{bmatrix}.\end{split}\]

A two-dimensional visualization of the weight space can then be written as

\[\mathbf{C}=\mathbf{W}\mathbf{V}_2,\]

where \(\mathbf{V}_2\) contains the first two principal directions of the weight-space representation.
